# Description

Sample file `inout.txt` in this directory contains a bascd is of 100 ECG functions for the lowest $^2 D^e$ state of Li atom (Li-7 isotope) and sets up calculations of expectated values for various quantities.
The calculations should take roughly 2-3 seconds on a single CPU core when double precision is used (gfortran compiler / AMD Ryzen 7 7800X3D).
