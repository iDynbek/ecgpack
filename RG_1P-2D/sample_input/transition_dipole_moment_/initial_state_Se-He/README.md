# Description

The sample file `inout.txt` in this directory contains a basis of 10 ECG functions for the lowest $^1 S^e$ state of the He atom (assuming infinite nuclear mass).
It generates the wave function expansion in separate files. The wave function name must be specified in the input file (`wavefunction.txt`).
The calculation should take approximately 1 second on a single CPU core when using double precision (gfortran compiler on an AMD Ryzen 7 7800X3D).
